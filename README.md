# Цветущий ход

«Цветущий ход» — бесконечная браузерная головоломка для Яндекс Игр. Игрок размещает фигуры на поле 8×8, очищает линии, накапливает цветение и восстанавливает уютную оранжерею.

## Локальный запуск

Для текущего инструментария используйте Node.js 20.19+ (или актуальную LTS-версию).

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm run test
npm run build
```

Готовая игра появляется в `dist/`. Сервер не требуется. Рисованные текстуры локально поставляются в WebP, игровое поле и эффекты отрисовываются Canvas, интерфейс — HTML/CSS. Внешних шрифтов и библиотек иконок нет.

`npm run package` пересобирает игру, обновляет `blooming-move-yandex.zip` и сохраняет **два датированных архива** в `backups/`: публикационную игру и исходники с текстурами, тестами и документацией. Нужны системные `zip`/`unzip`. Зависимости `node_modules`, Git-метаданные, личные файлы и старые архивы в резервную копию не включаются. Папки `backups/` и `artifacts/` остаются локальными; все исходники и ресурсы версии сохраняются в Git.

## Возможности

- Бесконечный рекордный режим и ежедневный вызов с общей базовой последовательностью. Каждый набор использует ровно шесть шагов PRNG; при отсутствии хода только третий слот заменяется резервным ростком. Сложность дня определяется номером набора, не очками игрока. Общая таблица дня отсутствует; цель 2000 и результаты дня — личные.
- Генератор фигур проверяет, что при выдаче есть хотя бы один легальный ход.
- Три честно заработанных умения: «Цветение» очищает 3×3 за четыре линии, «Капля росы» появляется за серию очисток и убирает одну клетку, а «Секатор» выдаётся за двойную очистку и срезает ряд с колонкой. Все цели выбирает сам игрок.
- Фигуры можно нажать или перетянуть на грядку; на поле появляется живая подсказка размещения.
- Тёплая оранжерея, независимые текстуры основы, клетки и рамки, объёмные цветочные плитки пяти цветов. Рамка не закрывает угловые клетки. Свои SVG-иконки, отдельные эффекты линий, цветения, росы и секатора. [Ассеты и промпты](docs/art-direction.md).
- Только одно добровольное продолжение за rewarded-видео. Автоматическая межэкранная реклама отключена; отсутствие или ошибка видео не завершает забег.
- Локальные сохранения после каждого хода; после добровольного входа — синхронизация профиля через Яндекс SDK.
- RU/EN с автоопределением языка, адаптивный touch/mouse-интерфейс, режим reduced motion.
- Живые цветы: мягкое несинхронное покачивание поля и фигур даже в ожидании хода. Выбранная фигура в руке неподвижна для точного управления. Пауза, скрытая вкладка и reduced motion останавливают движение.
- Предпросмотр будущей очистки: наведите выбранную фигуру, чтобы увидеть контур строк/столбцов, которые исчезнут. Это пояснение существующего правила, не автоматическая подсказка оптимального хода.
- Неподвижные слои поля кэшируются; спокойная Canvas-анимация рисуется до 30 кадров/с, эффекты хода — до частоты экрана. В фоне цикл отрисовки останавливается.

## Оранжерея и понятные правила

Оранжерея — действующая коллекция из пяти оформлений. Нажмите её карточку, просмотрите зоны и примените открытую. Меняется настоящий рисованный фон, а не цветовой фильтр. Выбор сохраняется после перезагрузки и входит в профиль для облачной синхронизации. Закрытые зоны можно посмотреть заранее.

| Зона | Всего нектара для открытия |
| --- | ---: |
| Тёплая грядка | 0 |
| Розовая галерея | 300 |
| Пруд кувшинок | 800 |
| Лунный зимний сад | 1500 |
| Купол цветов | 2500 |

Нектар начисляется **после завершения забега**: `max(5, floor(score / 25) + bestCombo * 4)`. Он не расходуется при выборе зоны и не влияет на фигуры, счёт или сложность. Новый профиль начинает с первой зоны; существующие награды сохраняются. [Рисованные сцены](docs/garden-art.md).

Кнопка «?» у поля открывает иллюстрированные правила: выбор одной из трёх фигур, размещение целиком на свободных клетках, очистка любой полной строки/столбца независимо от цвета. Там же объяснены комбо, заработок умений и нектара. Под полем подсказка меняется по ситуации. Нажатие на ещё не заработанное умение объясняет, как его получить.

Рамка отрисовывается позади клеток и фигур; у нижнего ряда есть внутренний отступ. Размер поля остаётся 8×8, в наборе остаётся три фигуры.

При ошибке или неизвестном формате облачного сохранения его перезапись блокируется. Локальная игра остаётся доступной; вход через профиль можно повторить. Это не заменяет проверку настоящей синхронизации в Консоли Яндекс Игр.

## Перед загрузкой в Яндекс Игры

1. Создайте игру в Консоли Яндекс Игр и настройте технический лидерборд `bloom_best`: numeric, descending, названия на русском и английском.
2. Подключите монетизацию. Игра сама безопасно обработает отсутствие или ошибку рекламы.
3. Выполните `npm run build`, затем упакуйте **содержимое** `dist/` в ZIP так, чтобы `index.html` лежал в корне архива.
4. В debug-панели Яндекс Игр проверьте Game Ready, паузу при рекламе/потере фокуса, RU/EN, сохранения и лидерборд.

На localhost подключается локальная заглушка платформы: она нужна, чтобы разработка проходила без ошибок SDK вне iframe Яндекс Игр. На опубликованном домене SDK загружается автоматически.

ZIP-хостинг Яндекс Игр подключает официальный `/sdk.js`. [Чек-лист требований и проверок в Консоли](docs/yandex-checklist.md). Локальная проверка не подтверждает прохождение модерации или работу реальной рекламы.

## Управление

Нажмите фигуру и клетку или перетащите фигуру мышью/пальцем. Клавиши 1–3 выбирают фигуру; стрелки перемещают курсор по полю, Enter ставит её, Escape отменяет умение или открывает паузу. Полноэкранный режим — по кнопке в настройках или при осознанном старте. Умения не покупаются: роса — за два последовательных хода с очисткой, секатор — за две линии одновременно, цветение — за четыре очищенные линии.

## Браузерная проверка

`scripts/visual-smoke.mjs` запускает отдельный временный профиль Chromium с тестовыми сохранениями и подставным SDK. Он не читает профиль пользователя. Требуется установленный Chrome и Playwright (можно задать путь пакета через `BLOOM_PLAYWRIGHT`); сервер `npm run dev` должен работать. Скриншоты проверки сохраняются в `artifacts/qa/`.

Запуск: `node scripts/visual-smoke.mjs`. Проверяет мышь, drag-and-drop, тач, перезагрузку, четыре размера окна, умения, линии, паузу SDK/меню, ошибки и награду видео, отмену входа. В настоящей Консоли отдельно проверить SDK, звук, Game Ready, облачную синхронизацию и лидерборд.
