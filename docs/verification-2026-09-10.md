# Проверка доработки оранжереи и интерфейса — 10 сентября 2026

Рабочая папка: `yandex_game`. Изменения продолжены после прерывания сеанса. Архивы и файлы пользователя в Downloads не изменялись. Тесты запускают изолированный профиль Chrome и не используют реальные сохранения пользователя.

## Изменения

- Меню режимов: выровнены заголовки, иконки и нижние действия; на узком экране варианты перестраиваются в одну колонку.
- Рамка теперь ниже клеток и фигур в порядке отрисовки, внутренний отступ согласован с координатами ввода. Поле остаётся 8×8, набор — три фигуры.
- Оранжерея: пять рисованных сцен, просмотр закрытых зон, понятная цель по нектару, выбор открытого оформления, реальная смена фона и восстановление выбора после перезагрузки.
- Нектар начисляется один раз за завершённый забег; выбор сцены бесплатный, косметический, не меняет баланс. Старые профили сохраняют награды.
- Иллюстрированная помощь RU/EN, подсказки по состоянию поля, объяснения комбо, заработка и применения каждого умения.
- Возврат из вспомогательного меню не оставляет игрока на завершённом поле. Фокус клавиатуры остаётся в открытом диалоге.
- Облачная запись запрещена до успешного чтения; ошибки и непустые неизвестные данные не считаются пустым профилем. Запросы записи сериализованы, включая повторный вход.

## Проверки

- `npm test`: 181 тест, 7 файлов, успешно.
- `npm run build`: TypeScript и Vite, успешно.
- `git diff --check`: успешно.
- `scripts/visual-smoke.mjs`: полный прогон в Chrome, exit 0, ошибок страницы нет.
- Мышь, перетаскивание, тач, клавиатура, загрузка сохранённого забега, границы поля, очистки и три умения.
- Полностью занятые тестовые клетки нижнего ряда, включая углы, видны целиком.
- Выбор сцены сохраняет игровое поле, фигуры, очки и накопленный нектар. Закрытую сцену нельзя применить. Лунная сцена и купол проверены с тестовым разблокированным профилем.
- Результат → режимы / оранжерея → результат; повторный заход не начисляет награду повторно.
- Восстановление фокуса после смены вкладки оранжереи, Tab/Shift+Tab, недоступность фоновых кнопок при диалоге.
- Ошибка rewarded и успешная награда; отмена авторизации; повторная ошибка облачного чтения без потери локального профиля и без записи в облако. SDK подставной.
- 1536×1024, 1366×768, 390×844, 320×568, 844×390. Меню, помощь и оранжерея помещаются в экран; длинное содержимое прокручивается внутри диалога.
- RU, EN fallback и reduced motion.
